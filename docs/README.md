# Elegy Documentation

## Overview

Elegy is a web-based document editor built with Django that provides a rich text editing experience with autosave functionality.

## Features

- Rich text editing with TipTap editor
- Autosave functionality
- Document management (create, edit, list)
- User authentication
- Responsive design with TailwindCSS

## Architecture

### Backend

- Django 5.0.3
- SQLite database
- WhiteNoise for static file serving
- Django Debug Toolbar for development

### Frontend

- TipTap editor
- Alpine.js for reactivity
- TailwindCSS for styling
